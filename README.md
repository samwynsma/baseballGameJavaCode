# baseballGameJavaCode
This file contains code for a baseball simulator. It takes in a play and updates the game as necessary.
The plays include the following:
Ball, Strike, Out, Intential Walk, Error, Steal 2nd/3rd/home, Single, Double, Triple, Home Run, Passed Ball, and others.
The application also has the ability to display what one might see on the Chiron, which is the indicator on a television screen during a baseball game that shows to viewers the status of the game.
This application will eventually have a visual aid to allow the status of the game to be visible.
